 Carbium

Carbium is a lightweight EPUB reader application built with Flutter.

 Features

-   Authentication: Secure Login and Signup.
-   Library: Import and manage your EPUB collection.
-   Reader: 
    -   Scroll and Paged reading modes.
    -   Customizable fonts and sizes.
    -   Sepia mode for comfortable reading.
    -   Full-text search within books.
-   Bookmarks: Save your place with notes (synced per user).
-  User Profiles: Personalized experience with data isolation.
